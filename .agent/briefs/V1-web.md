## Goal
The web app shell and the **UI-quality harness** every later task builds on: router with role layouts and placeholder pages, 404, i18n with the `en-XA` pseudo-locale, TanStack Query defaults + key factory, `PrefetchLink`, top progress bar, Suspense inside layouts, route `errorElement`, skeleton primitives, money/date formatting, public-config fetch; plus the e2e harness (`layout-audit`, `layout.spec.ts`, `states.spec.ts`, home spec, stress fixtures) and bundle budgets.

## Build (paths under `apps/web/src/` unless noted)
1. `vite.config.ts`: react + tailwind plugins; `server.port` from env `WEB_PORT` (default 5173), `preview.port` from `E2E_WEB_PORT` (default 4173); **proxy** `/api` and `/socket.io` (ws) to `process.env.API_PROXY_TARGET ?? 'http://localhost:4000'` for both `server` and `preview`; `build.sourcemap: 'hidden'`.
2. `main.tsx`, `app/providers.tsx` (QueryClientProvider, i18n), `app/router.tsx`: `createBrowserRouter`; every page via route `lazy`. Routes (placeholders now, real pages in later tasks): AuthLayout → `/` landing, `/login`, `/signup`; LandlordLayout (`/l`, `/l/buildings`, `/l/billing`, `/l/payments`, `/l/maintenance`), the same layout for caretaker `/c`; TenantLayout (`/t`, `/t/bills`, `/t/requests`, `/t/notices`, `/t/account`); AdminLayout `/a`; shared `/account`; `*` → NotFound. Every route has `errorElement: <RouteError/>` (Retry = `navigate(0)`/revalidate + link home). **No loaders that await data.**
3. Layouts `app/layouts/*.tsx`: each renders its shell (landlord/admin: sidebar ≥ md, top bar + bottom tab bar < md with ≤ 5 items; tenant: bottom tab bar with Home, Bills, Requests, Notices, Account; desktop centred column ≤ 720 px with top nav) and `<Suspense fallback={<RouteSkeleton/>}>` **around the `<Outlet/>` inside the layout** (ui-states rule 1). Nav links are `PrefetchLink`s with the active state from `NavLink` semantics; bottom nav has `data-bottom-nav`, ≥ 56 px tall + safe-area padding; `<main>` has bottom padding ≥ that height on mobile. Follow every **mobile-layout-qa build rule** (min-w-0, whitespace-nowrap labels, 44 px targets, `min-h-dvh`, inputs ≥ 16 px).
4. Placeholder pages: a heading + one data region that uses `useQuery(publicConfigQuery)` and shows `<Skeleton>` while pending, an error card with Retry on error, content on success (e.g. "Environment: dev"). This lets the states spec exercise real pending/error states until real data arrives in later tasks.
5. `lib/api/client.ts`: `apiFetch<T>(path, {schema, method, body, signal})` → parses `{data}` with the Zod schema, throws `ApiRequestError` (`status`, `code`, `message`, `requestId`) parsed with `errorBodySchema`; never called from components directly. `lib/api/queryClient.ts` exactly per ui-states rule 2 defaults (no retry on 4xx). `lib/api/keys.ts` query-key factory (`keys.publicConfig()`, pattern for later modules). `lib/api/publicConfig.ts` (`publicConfigQuery` options + `usePublicConfig()`), fetched once at startup in `providers.tsx` (prefetch, not blocking render).
6. `lib/router/PrefetchLink.tsx`: wraps React Router `Link`; on `pointerenter`, `focus`, `touchstart` calls a `prefetch` prop (route chunk preload + `queryClient.prefetchQuery`) once; a registry `lib/router/preload.ts` mapping paths → `() => import(...)` page modules (the same functions the router's `lazy` uses, so preloading actually warms the chunk). After first paint, idle-preload (`requestIdleCallback` fallback `setTimeout`) the role's nav routes.
7. `components/ui/TopProgressBar.tsx` (2 px, accent token, shows when `useNavigation().state !== 'idle'` for > 150 ms, `role="progressbar"` `aria-label`), `components/ui/Skeleton.tsx` (`data-skeleton`, `aria-busy`, respects reduced motion), `components/ui/RouteSkeleton.tsx`, `components/ui/ErrorState.tsx` (message + Retry), `components/ui/EmptyState.tsx`, `pages/shared/NotFound.tsx`, `pages/shared/RouteError.tsx`.
8. `lib/i18n.ts`: i18next + react-i18next, resources from `locales/en/*.json` (namespace `common` for now). **`en-XA` pseudo-locale** generated at init from `en` (accent letters, pad +40% with `·`, wrap in `[ ]`, keep `{{interpolations}}` intact), available in dev/test builds and selected with `?lng=en-XA` (persisted in `localStorage` key `bm.lng`). No hard-coded user-facing English in components.
9. `lib/format.ts`: `formatMoney(poisha: number|bigint)` → `৳12,500` / `৳1,25,000` (`Intl.NumberFormat('en-IN')`, whole taka unless non-zero poisha then 2 decimals, negative as `−৳12,500` with U+2212), `formatDate(iso)` → `10 Nov 2026`, `formatMonth('2026-11-01')` → `November 2026`, all in `Asia/Dhaka`.
10. `styles/tokens.css` (temporary, see Goal) + `styles/globals.css` (`@import "tailwindcss"`, `@theme` mapping the tokens so utilities like `bg-surface text-fg border-border` work, focus-visible ring, reduced-motion).
11. Unit tests (`src/**/*.test.ts(x)`, jsdom, setup file `src/test/setup.ts` importing `@testing-library/jest-dom/vitest`): `format` (the examples above incl. ৳1,25,00,000 and negative), pseudo-locale transform, `apiFetch` (success parse, error body → `ApiRequestError`), `PrefetchLink` (calls prefetch once on hover/focus), `TopProgressBar` (hidden when idle).
