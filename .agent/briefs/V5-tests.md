## Interface (the implementer builds exactly this; routes/bodies/error codes from 04)
- Routes under `/api/auth/*`, `/api/invites/*`, `/api/me*` per 04. Cookies: `bm_at` (HttpOnly, SameSite=Lax, Path=/, 15 min), `bm_rt` (HttpOnly, SameSite=Strict, Path=/api/auth, 30 days, opaque, stored only as SHA-256), `bm_csrf` (readable, double-submit). `Secure` follows `COOKIE_SECURE`. Unsafe methods need `X-CSRF-Token` = `bm_csrf` **and** `Origin` = `APP_URL`, else 403 `FORBIDDEN`.
- `tests/helpers/auth.ts` (you write it): `signupAndVerify(agent, …)`, `loginAs(agent, email, password)` → Supertest agent with cookies + CSRF header set; `csrfFrom(agent)`. Mail via Mailpit's HTTP API (`MAILPIT_URL` env, test port 8026): `latestMailTo(email)`, `extractLink(mail, path)`.
- Rate limits use Redis (`rate-limit-redis`); tests flush the Redis test DB between files.
- Google OAuth: the callback's token exchange and userinfo go through an injectable `googleClient` (`apps/api/src/modules/auth/google.ts` exports the interface + `setGoogleClientForTests(fake)` available only when `APP_ENV=test`). Test with a fake: verified matching email links; unverified matching email → no link, redirect `/login?error=google_failed`; new email → creates landlord account + org (org name from the Google profile name + "'s properties"); with `invite` state → accepts the invite.
- Sockets: `apps/api/src/realtime/io.ts` `attachRealtime(server, deps)`; `logout-all` and reset-password emit `session:revoked` to `user:<id>` and disconnect that user's sockets. Test with `socket.io-client` (dev dep; the lead adds it) connecting with the `bm_at` cookie.
