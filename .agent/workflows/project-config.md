### Secrets Rony provides (never in the repo, never in chat)
All go into **`D:\Projects\Project_credentials\BasaManager.env`** (outside the repo). Agents read that
file by variable name, push values to GitHub Environment secrets (`staging`, `production`) with
`gh secret set` and to the VPS `.env` files over SSH, and **never print a value** (check presence by
length only).

Exact steps per platform: [`../CREDENTIALS-GUIDE.md`](../CREDENTIALS-GUIDE.md). Variables:
`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ZONE_ID`, `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`,
`CLOUDINARY_API_SECRET`, `RESEND_API_KEY`,
`GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`, `SENTRY_AUTH_TOKEN`, `SENTRY_ORG`, `SENTRY_DSN_WEB`, `SENTRY_DSN_API`, `SENTRY_DSN_WORKER`,
`SSLCOMMERZ_STORE_ID`, `SSLCOMMERZ_STORE_PASSWORD`, optional `UPTIMEROBOT_API_KEY`.
Only Claude agents (DevOps) read this file. `agy` coding sessions never get it.

Generated by agents, not Rony: JWT signing keys, VAPID web-push keys, seed/e2e user passwords, database passwords, Redis password, the cookie/CSRF
secrets, the deploy SSH key, the local-storage URL secret, the Azure backup SAS token. Agents generate them with a CSPRNG and store
them only in the GitHub Environment secrets and the VPS `.env` files (mode 600).

## Steps
1. For each CLI: run its version/auth check (`gh auth status`, `az account show`, `docker info`, …).
   A missing or logged-out tool is a ❌ with the exact command for Rony.
2. MCP servers: `claude mcp list`. Enable the needed ones; disable the "Not used" ones **for this
   project only**. A missing server that needs no secret (`chrome-devtools`, `shadcn`) may be added
   with `claude mcp add --scope project …`. Never edit global config.
3. Write grants in `.claude/settings.local.json` (git-ignored): `mcp__chrome-devtools`, `mcp__shadcn`,
   `WebFetch(domain:<host>)` for every URL above, and `Bash(pnpm *)`, `Bash(npx *)`, `Bash(node *)`,
   `Bash(git *)`, `Bash(gh *)`, `Bash(agy *)`, `Bash(az *)`, `Bash(docker *)`, `Bash(ssh *)`, `Bash(scp *)`.
4. Secrets: read `D:\Projects\Project_credentials\BasaManager.env`; for every variable in the table,
   report ✅ present (length N) / ❌ missing. Never print values.
5. Check each tool answers for real: one read-only call per MCP server and CLI.
6. Write the **Builder setup** table into `.agent/PROGRESS.md` → "Environment facts": item · ✅/❌ ·
   what was done / what Rony must do · date. Add each ❌ to "Human steps".
7. Report: ✅ done, ❌ needs Rony (exact step each). Then: "When the ❌ list is empty, paste the goal command."
