# Decisions (ADRs)

An ADR (architecture decision record) is one page per key decision: the context, the options that were
considered, what was chosen, and the consequences you now live with. When you are asked "why did you build it
this way?", the answer is here.

| ADR                                    | Decision                                                     |
| -------------------------------------- | ------------------------------------------------------------ |
| [ADR-001](/decisions/ADR-001-monorepo) | One pnpm monorepo with shared packages instead of many repos |

The key decisions that are already made are listed in `AGENTS.md` ("Key decisions"). Each one gets its own ADR
page as the task that implements it is written; the set is completed in task V17.
